Docker & Kubernetes Nginx Deployment

Containerized Application Deployment Project

This project demonstrates the complete deployment lifecycle of a web application using Docker and Kubernetes.

The application was containerized using Docker, published to Docker Hub, and deployed on a Kubernetes multi-node cluster using Deployments and NodePort Services.

Technology Stack

Docker • Docker Hub • Kubernetes • Nginx • Containerd • Calico • Linux

Key Features

✓ Custom Docker Image Creation

✓ Docker Hub Image Publishing

✓ Kubernetes Deployment Management

✓ NodePort Service Configuration

✓ Multi-Node Cluster Deployment

✓ End-to-End Application Validation
