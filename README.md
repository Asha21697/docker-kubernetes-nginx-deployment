# Docker Nginx Deployment Project

## Overview
This project demonstrates how to containerize a custom Nginx web application using Docker.

## Technologies Used
- Docker
- Nginx
- Linux

## Project Workflow
1. Installed and verified Docker.
2. Created a custom HTML page.
3. Created a Dockerfile.
4. Built a custom Docker image.
5. Ran the Docker container.
6. Verified application accessibility in the browser.
7. Tagged and pushed the image to Docker Hub.
